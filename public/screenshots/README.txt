Appreciation / recognition screenshots
======================================

1. Save images here (PNG or JPG):
   - genesis-bnb-win.png
   - litchess-discord.png
   - etc.

2. Open lib/data.ts and find "signals".

3. Set the image path on a card, for example:

   {
     org: "LitVM Core Team",
     project: "LitChess",
     text: "His dApps show real product thinking.",
     image: "/screenshots/litchess-discord.png",
     href: "https://optional-link.com",
   }

4. Refresh the site — the screenshot appears above the quote.

Tips:
- Crop to the message only
- Prefer dark backgrounds
- Keep file size under ~1MB if you can
